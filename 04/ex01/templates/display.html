Ex01: Display process of a static page

Overview

The process of displaying a static web page in Django involves several components working together. Here's the complete flow from receiving a request to sending back a response.

The Request-Response Cycle

1. User Makes a Request

When a user enters a URL in their browser or clicks a link, an HTTP request is sent to the Django server. This request contains information such as the URL path, HTTP method (GET, POST, etc.), headers, and any data.

2. URL Routing

Django's URL dispatcher receives the request and examines the URL pattern. It compares the requested URL against the patterns defined in the urls.py file, starting from the root URLconf specified in settings.py. When a match is found, Django calls the associated view function.

3. View Processing

The view function is a Python function that receives the HTTP request object as its first parameter. For a static page, the view typically performs the following actions:

  • Receives the HTTP request object
  • Optionally prepares context data (a dictionary of variables to pass to the template)
  • Calls the render() function with the request, template name, and context

4. Template Rendering

The Django template engine processes the specified template file:

  • Loads the template from the templates directory
  • Parses the template, identifying Django template tags and variables
  • Replaces template variables with values from the context
  • Processes template tags (loops, conditionals, blocks, includes, etc.)
  • Generates the final HTML document

5. HTTP Response

The rendered HTML is wrapped in an HttpResponse object, which includes:

  • The HTML content
  • HTTP status code (200 for success)
  • HTTP headers (content-type, cookies, etc.)

6. Response Delivery

Django's web server sends the HTTP response back to the user's browser through the network. The browser receives the response and renders the HTML, displaying the static page to the user.

Key Components

  • urls.py: Maps URL patterns to view functions
  • views.py: Contains view functions that process requests
  • templates/: Directory containing HTML template files
  • Template Engine: Processes templates and generates HTML
  • settings.py: Configuration file that specifies project settings

Example Flow

Request: http://localhost:8000/ex01/display/

  1. Django receives request for /ex01/display/
  2. Root urls.py routes to ex01.urls
  3. ex01/urls.py matches pattern and calls display_page view
  4. View function calls render(request, 'display.html')
  5. Template engine loads and processes display.html
  6. HTML is returned as HTTP response
  7. Browser displays the page

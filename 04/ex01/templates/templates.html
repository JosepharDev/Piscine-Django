Ex01: Template engine

Django's Default Template Engine

Django's template engine is a powerful system for generating HTML dynamically. It's designed to feel comfortable to those used to working with HTML, while providing powerful features for creating dynamic content.

How the Template Engine Works

The Django template engine processes templates in several steps:

  1. Loading: Django locates and loads the template file from the templates directory
  2. Parsing: The template is parsed to identify template tags, variables, and filters
  3. Rendering: Variables are replaced with their values from the context, and template tags are executed
  4. Output: The final HTML document is generated and returned

Blocks

Blocks are used for template inheritance, allowing child templates to override specific sections of a parent template.

Parent Template (base.html):

{% verbatim %}


    {% block title %}Default Title{% endblock %}


    {% block content %}{% endblock %}


{% endverbatim %}

Child Template:

{% verbatim %}
{% extends 'base.html' %}

{% block title %}My Page{% endblock %}

{% block content %}
    
Hello World!

{% endblock %}
{% endverbatim %}

Blocks allow you to define sections in a base template that can be overridden by child templates, promoting code reuse and maintaining consistency across pages.

For Loops

The {% templatetag openblock %} for ... in {% templatetag closeblock %} tag allows you to iterate over sequences like lists, tuples, or querysets.

Basic Syntax:

{% verbatim %}

    
{% for item in items %}
    
  • {{ item }}
    • 
{% endfor %}


{% endverbatim %}

With Empty Clause:

{% verbatim %}
{% for item in items %}
    
{{ item }}

{% empty %}
    
No items available.

{% endfor %}
{% endverbatim %}

Loop Variables:

Django provides special variables inside for loops:

  • forloop.counter: Current iteration (1-indexed)
  • forloop.counter0: Current iteration (0-indexed)
  • forloop.first: True if first iteration
  • forloop.last: True if last iteration
  • forloop.parentloop: Reference to parent loop in nested loops

If Control Structures

The {% templatetag openblock %} if {% templatetag closeblock %} tag allows conditional rendering of content.

Basic If Statement:

{% verbatim %}
{% if user.is_authenticated %}
    
Welcome, {{ user.username }}!

{% endif %}
{% endverbatim %}

If-Else Statement:

{% verbatim %}
{% if items %}
    
There are items.

{% else %}
    
No items found.

{% endif %}
{% endverbatim %}

If-Elif-Else Statement:

{% verbatim %}
{% if score >= 90 %}
    
Grade: A

{% elif score >= 80 %}
    
Grade: B

{% elif score >= 70 %}
    
Grade: C

{% else %}
    
Grade: F

{% endif %}
{% endverbatim %}

Logical Operators:

You can use and, or, and not operators:

{% verbatim %}
{% if user.is_authenticated and user.is_staff %}
    
Admin access granted

{% endif %}
{% endverbatim %}

Displaying Context Variables

Variables passed from views to templates through the context can be displayed using double curly braces.

Basic Variable Display:

{% verbatim %}

Hello, {{ name }}!

{% endverbatim %}

Accessing Object Attributes:

{% verbatim %}

{{ user.username }}


{{ product.price }}

{% endverbatim %}

Accessing Dictionary Keys:

{% verbatim %}

{{ data.key }}

{% endverbatim %}

Accessing List Items:

{% verbatim %}

{{ items.0 }}

{% endverbatim %}

Using Filters:

Filters modify variables for display:

{% verbatim %}

{{ name|upper }}


{{ text|truncatewords:30 }}


{{ price|floatformat:2 }}


{{ date|date:"Y-m-d" }}

{% endverbatim %}

Summary

Django's template engine provides a clean separation between presentation and logic, making it easy to create maintainable and reusable templates. The combination of blocks, loops, conditionals, and variable display creates a powerful system for generating dynamic HTML content.

Ex01: Django, framework web

Introduction to Django

Django is a high-level Python web framework that encourages rapid development and clean, pragmatic design. Built by experienced developers, it takes care of much of the hassle of web development, so you can focus on writing your app without needing to reinvent the wheel. It's free and open source.

History of Django

Django was created in 2003 by Adrian Holovaty and Simon Willison while working at the Lawrence Journal-World newspaper in Kansas. The framework was named after the famous jazz guitarist Django Reinhardt.

In July 2005, Django was released to the public under a BSD license. The first official version, Django 1.0, was released in September 2008.

Key Features

  • Fast: Django was designed to help developers take applications from concept to completion as quickly as possible.
  • Secure: Django takes security seriously and helps developers avoid many common security mistakes.
  • Scalable: Some of the busiest sites on the web leverage Django's ability to quickly and flexibly scale.
  • Versatile: Django has been used to build all sorts of things — from content management systems to social networks to scientific computing platforms.

Django Philosophy

Django follows several important design philosophies:

  • Don't Repeat Yourself (DRY): Every distinct concept and/or piece of data should live in one, and only one, place.
  • Loose Coupling: The various layers of the framework should be independent of each other where possible.
  • Explicit is better than implicit: Django should be clear about what it's doing.
  • Consistency: Django is consistent at all levels.

Evolution Over Time

Since its initial release, Django has undergone significant development with major version releases introducing new features, improvements, and enhanced security. The Django Software Foundation, established in 2008, continues to support and maintain the framework.

Django has maintained backward compatibility as much as possible while evolving to meet modern web development needs. The framework has grown from a simple web publishing tool to a comprehensive web framework used by millions of developers worldwide.

Ex00: Markdown Cheatsheet

Headers

# H1
## H2
### H3
#### H4
##### H5
###### H6

Emphasis

Syntax Result
*italic* or _italic_ italic
**bold** or __bold__ bold
***bold italic*** bold italic
~~strikethrough~~ strikethrough

Lists

Unordered Lists

* Item 1
* Item 2
  * Item 2a
  * Item 2b

- Item 1
- Item 2

+ Item 1
+ Item 2

Ordered Lists

1. First item
2. Second item
3. Third item
   1. Indented item
   2. Indented item

Links

[Link text](https://www.example.com)
[Link with title](https://www.example.com "Link Title")

<https://www.example.com>

[Reference-style link][reference text]
[reference text]: https://www.example.com

Images

![Alt text](image.jpg)
![Alt text](image.jpg "Image Title")

![Reference-style image][logo]
[logo]: image.jpg "Logo Title"

Code

Inline Code

Use `code` in your sentence.

Code Blocks

```python
def hello_world():
    print("Hello, World!")
```

```javascript
function helloWorld() {
    console.log("Hello, World!");
}
```

    Indented code block
    with four spaces

Blockquotes

> This is a blockquote.
> It can span multiple lines.
>
> > Nested blockquote

Horizontal Rules

---
***
___

Tables

| Header 1 | Header 2 | Header 3 |
|----------|----------|----------|
| Cell 1   | Cell 2   | Cell 3   |
| Cell 4   | Cell 5   | Cell 6   |

| Left | Center | Right |
|:-----|:------:|------:|
| L1   |   C1   |    R1 |
| L2   |   C2   |    R2 |

Task Lists

- [x] Completed task
- [ ] Incomplete task
- [ ] Another task

Footnotes

Here's a sentence with a footnote.[^1]

[^1]: This is the footnote.

Definition Lists

Term 1
: Definition 1

Term 2
: Definition 2a
: Definition 2b

HTML

You can also use raw HTML in Markdown:

<div>
    <p>HTML content</p>
</div>

Escaping Characters

Use backslash to escape special characters:

\* Not italic \*
\# Not a header
\[Not a link\](url)

Line Breaks

End a line with two spaces  
to create a line break.

Or use an empty line

to create a paragraph break.

Comments

<!-- This is a comment -->

Automatic Links

<https://www.example.com>
<email@example.com>

Extended Syntax (GitHub Flavored Markdown)

Alerts

> [!NOTE]
> Useful information

> [!TIP]
> Helpful advice

> [!IMPORTANT]
> Key information

> [!WARNING]
> Critical content

> [!CAUTION]
> Potential risks

Syntax Highlighting

```diff
- removed line
+ added line
```

Emojis

:smile: :heart: :thumbsup:

Subscript and Superscript

H~2~O (subscript)
X^2^ (superscript)

Highlighting

==highlighted text==

Abbreviations

*[HTML]: Hyper Text Markup Language
